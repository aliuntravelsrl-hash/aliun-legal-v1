## Metodología de versiones

| Versión | Cuándo |
|---------|--------|
| v1.0 | Documento nuevo sellado |
| v1.1, v1.2 | Ajustes menores (redacción, datos) |
| v2.0 | Cambio estructural o legal significativo |

**Regla:** nunca sobreescribir una versión vigente.
Al actualizar → crear nueva versión → actualizar INDICE.md.

---

## Cómo se actualiza este repo

1. ATLAS-TECH redacta el documento en Markdown
2. Director revisa y aprueba
3. ATLAS-TECH hace commit con número de versión
4. INDICE.md se actualiza con nuevo estado
5. Si va a la web → Antigravity despliega el HTML
